# Résultats
Chaque exécution de `python -m src.train` produit un `resume.json` (graine, catégorie, seuils calibrés, AUROC, IoU/Dice brut et filtré, MAE de surface, latence) ainsi que des figures d'exemples.
Les résultats retenus pour le rapport (catégorie et graine fixées) sont copiés dans ce dossier avec un tableau récapitulatif.
